# Requisitos para Cadastro   

# RF01 - Nome
- O usuário deve digitar seu nome.

# RF02 - Sobrenome
- O usuário deve digitar seu sobrenome

# RF03 - E-mail
- O usuário deve informar um endereço de e-mail válido e, caso ainda não esteja cadastrado, o sistema deve aceitá-lo

# RF04 - Data de Nascimento
- O usuário deve informar sua data de nascimento.

# RF05 - Senha
- O usuário deve informar uma senha com no mínimo 8 caracteres, contendo pelo menos 1 letra maiúscula e 1 caractere especial.

# RF06 - Confirmação de Senha
- A senha deve ser IGUAL a senha digitada anteriormente.

# RF07 - E-mail Duplicado
- O sistema NÃO deve permitir o cadastro de um email jã existente no banco de dados.

# RF08 - Cadastro Válido
- Com todos os dados válidos, o sistema deve realizar o cadastro com sucesso.
